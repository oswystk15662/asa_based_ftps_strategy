# 技術リスクと代替案

| リスク | 影響 | 判断・対処 | 代替案 |
|---|---|---|---|
| AsaApi と対象 ASA ビルドの不一致 | 起動時停止、ネイティブ呼び出しでサーバー停止 | 01–02 で互換を確認。版を固定し更新前に再検証。オフセットの欠落で実体を書き換えない | 既知互換の隔離セット、バニラ＋仮想アダプター |
| 人間型 NPC の外部制御契約が未確認 | 主なゲーム表現の一部が成立しない | 11a 観測、06/07、11b の順に版付きで合否。作者の公開情報または確認済みの契約を使う | 論理人口、既存 NPC の観測連携。独自 NPC には制作・配布を再判断 |
| 既存建築の初期化・スナップ・保存 | 表示・支持・所有・復元がずれる | 04/05/10/13。通常配置の結果と比較し、座標・所有・区画を限定 | 手動配置した既存部材の観測、仮想道路 |
| 保存の非原子性・永続 ID 不確実 | 生成と資材の重複、誤削除 | 13 で ACK 喪失、バックアップの片側巻戻し、既存設備破壊を注入 | 完全観測を待つ、管理対象を限定、保留と手動照合 |
| World Partition・休眠 | 未観測の構造物を欠落と誤判定、読めない地形へ配置 | 12 で滞在、再訪、無人時間、列挙・衝突を測定 | 遠隔を外部で処理し、変更計画を次に観測できる時点へ |
| 同居時の RAM・空き容量 | FPS/ティック低下、更新失敗 | サーバーのみを先に測定。クライアント/追加ツールは空きと作業領域を確認後 | クライアント・サーバー分離または外部演算移行 |
| CPU/メインスレッド圧迫 | コマンド滞留・ネット遅延 | 14 で tick 時間、同時 NPC・部材数を段階測定。有界の処理計画 | 詳細度を下げる、バッチ調整、重い計算だけ外部で最適化 |
| MOD の版・配布・規約 | 更新でパスまたは挙動が変わる | 正規配布版を記録。自然スポーンと公開契約のみを依存候補とする | MOD を必須依存から外す |
| 独自メッシュ・地形改変 | DevKit 容量と制作・配布負担、ランタイム改変経路未確認 | 独自アセットの必要性を検討後、公式制作手順と配布設計を別判断 | 土台、天井、柱、スロープ、橋、路線変更 |
| 通信切断・誤った接続先 | 古いコマンドの適用、ゲーム内状態の食い違い | localhost、boot_id、期限、再同期。03/13 で障害注入 | 読み取りに戻し、再照合後に再開 |
