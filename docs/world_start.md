# 世界の開始時代とプレイヤーの選択

## 出身地と前世の記憶

出身地は、最初に学べる地域技術と、出会う人物や仕事に影響する。都市の初期技術はその都市の産業を表す。プレイヤーがその技術を覚える経路は、師匠、仕事、他地域での修業などを想定する。 [土地柄と初期技術の試作](ragnarok_technologies.md)

前世の記憶は物語の途中で現れ、どう受け止め、誰に話し、行動に移すかをプレイヤーが選ぶ。キャラクター作成時に前世の職業や戦闘・生産の補正を割り当てる仕組みは設けない。選択の結果は、次に会える人物、任される仕事、街の信用、後から使える解決手段に反映する。

たとえば、砂漠で井戸の水位が下がったとき、前世で見た貯水設備を思い出す。井戸守に相談すれば水の配分を見直す仕事につながる。隊商に知らせれば代わりの補給地を探す仕事が始まる。記憶を胸にしまって現地の職人の話を聞けば、地下水路の修繕を学べる。どの経路を通っても、水をどう使ったかに応じて後の交易や人間関係が変わる。

結果を記録する単位は、キャラクター、出来事、選んだ行動とその結果。再接続時は確定済みの結果を読み込み、同じ選択で報酬や信用が重複しないようにする。ワールドの記録は、プレイヤーの選択から実際に発生した変化を扱う。

## ワールド作成時の設定

「世界の開始時代」は、人口、在庫、地域技術、施設、街道と、必要に応じて勢力の関係をまとめて指定する。新しいワールドを作成したときに初期状態として保存し、以後はそのセーブを進める。設定値はゲーム内の年数に換算せず、開始時点の規模と稼働状況で決める。

| 開始時代 | 初期状態 | 主な遊び方 |
|---|---|---|
| 開拓期 | 小集落、井戸、小さな倉庫、短い道 | 最初の産業と交易を自分たちで成立させる |
| 都市成立期 | 市場のある港町、井戸と倉庫のあるオアシス、鉱山集落、主要街道 | 都市の仕事や修業を足がかりに、辺境の小集落を育てる |
| 交易圏の時代 | 大都市が複数、港、専門工房、定期便、勢力間の取り決め | 既存の市場に参入し、代替産地や短い交易路を開く |
| 旧文明の崩壊後 | 大都市の遺跡、途切れた街道、現役の小集落 | 遺構や水路を復旧し、途絶えた交易を再開する |

先行する試作は都市成立期。Viking Bay の港町で食料を加工し、砂漠のオアシスが隊商に水を供給し、鉱山集落が金属の原料を出す構想。大都市の周辺にも小さな集落を置き、プレイヤーは都市で仕事を得たり、自分の拠点を育てたりできる。

外部シミュレーターの合成地図に、人口 120 の港町、48 のオアシス、18 の鉱山、8 の開拓集落を配置した。初期街道は 6 区間で、港町・オアシス・鉱山には土台があり、鉱山には精錬所もある。最初の tick に港町からオアシスへ既存街道で食料を送り、tick 4 に到着した。開拓集落は通常どおり土台の資材を予約する。

```sh
python -m simulator.civilization --database established.sqlite --scenario configs/established-world-demo.json --ticks 4
```

開始時の道路は `starting_roads`、都市の既設土台と産業は `starting_foundation`、`starting_industry` で指定する。既設分の資材は開始時の在庫から再度差し引かない。砂漠の水や塩、前世の記憶による分岐は設計段階。

## 砂漠の都市と交易

| 土地柄 | 初期技術案 | 交易上の役割 |
|---|---|---|
| オアシス | 地下水路 | 水と野菜を供給し、木材と工具を得る |
| 砂丘街道 | 隊商案内 | 井戸を結ぶ案内、宿泊、荷の中継を提供する |
| 岩砂漠の峡谷 | 日干し煉瓦 | 煉瓦と陶器を輸出し、食料を得る |
| 塩原 | 製塩 | 保存用の塩を湾岸に出し、水と穀物を得る |
| 砂漠の縁 | 乾燥農法 | 少ない水で穀物を育て、砂漠の町や隊商に供給する |

砂漠の塩を港町で魚の保存に使い、保存食を隊商へ送る。井戸や道路が使えなくなった場合は代替拠点を探すことになり、遠方の港町にも納期や在庫の変化が出る。各拠点の配置と資源量は、Ragnarok の実地確認に合わせて決める。
