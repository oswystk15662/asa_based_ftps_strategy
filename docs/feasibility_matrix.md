# 機能別実現可能性

2026-11-24 JST。対象は AsaApi 2.11 / Windows 専用サーバー。根拠 S1–S12 と MOD の出典は [API 調査](api_research.md)。検証番号は [PoC 計画](poc_plan.md)。この表は公開ソースと設計に基づく判定。実機検証待ち。

A は AsaApi の公開インターフェースで直接操作できる範囲。B は公開ヘッダーに見えるネイティブ呼び出しも含め、ゲーム側の内部状態・フック・ライフサイクルに依存するもの。C は既存 MOD 依存、D は外部代替、E は新規制作・配布に DevKit が必要、F は現時点で採用困難、U は成立する呼び出し未確認。難度は低・中・高、更新破損リスクは小・中・大。D の更新リスクは ASA との変換境界に適用。
